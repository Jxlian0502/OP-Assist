# OP-Assistent

Fabric-Client-Mod für **Minecraft 1.21.11** auf dem Server **OPSUCHT**: AH-Preise im Tooltip, Markt-Overlay,
Jobtracker, Inventar-Knöpfe, Speed-Anzeige und vieles mehr.

## Download

Aktuelle Version: [`dist/`](dist/) → die `op-assistent-….jar` anklicken → Download.

## Installation

1. Fabric für **Minecraft 1.21.11** (oder LabyMod mit Fabric)
2. **Fabric API** in den `mods`-Ordner
3. Die `op-assistent-….jar` in den `mods`-Ordner
4. Starten. Updates kommen danach automatisch (beim Start geladen, beim Beenden installiert).

Einstellungen im Spiel: `/opa einstellungen`
